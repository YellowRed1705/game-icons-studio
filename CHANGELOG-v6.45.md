# Game Icons Studio v6.45 — compact, no-scroll home dashboard

- Reworks the eight primary home actions into a consistent four-column, two-row desktop dashboard.
- Reduces button height, padding, icon size, title size, description size and vertical gaps.
- Keeps the home layout short enough for typical desktop viewports, avoiding a scroll bar just to reach the main options.
- Uses a responsive two-column layout on screens at or below 780px.
- Adds a short-height desktop adjustment for compact windows.
- Adds Windows regression assertions for dashboard grid, compact button sizing and responsive layout.

## Upgrade
- Full package: `Game-Icons-Studio-v6.45.zip`.
- Existing installation: close Game Icons Studio and extract `Game-Icons-Studio-v6.45-Upgrade.zip` over the existing application folder.
