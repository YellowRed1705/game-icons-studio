Game Icons Studio v6.43 — Upgrade Instructions

1. Close Game Icons Studio.
2. Download Game-Icons-Studio-v6.43-Upgrade.zip from GitHub Releases.
3. Extract its contents over your existing Game Icons Studio folder and approve replacement of application files.
4. Start Game Icons Studio.bat and run Game Library Folder again.

What changed
- Emulator launcher shortcuts such as Cemu, Eden and Ryujinx/Ryubing are no longer omitted from artwork matching just because they have no command-line arguments.
- They are routed through Program & App Icons, while their executable paths remain available as emulator profiles for ROM launch shortcuts.
- Game shortcuts continue to use SteamGridDB game artwork.
- The Game Library scan summary reports how many emulator/application shortcuts were included.

No existing shortcut launch targets or ROM arguments are rewritten by this detection change. Only selected icon artwork is applied during the normal review/apply step.
